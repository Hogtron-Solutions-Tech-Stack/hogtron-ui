# HogHeals Module 2 — `HogHeals_HUD` Design

Date: 2026-09-14
Status: APPROVED by Sean 2026-09-14 (design + "build now"); overrides roadmap rule "Frames ships first"
Author: Sean Bilger + Claude (Fable 5.1)
Parent spec: `2026-09-13-hogheals-frames-design.md` (core, conventions, testing rails)

## 0. Why

A healer's second screen: what am I casting, what mana do I have, when does it tick, will I go OOM,
and which rank should I press. Replaces four addons Sean runs today (Quartz, FiveSecondRule, Gnosis,
ShamanPower's display). Every data source is the player's own state (casts, mana, spellbook, +healing)
→ safe under any Forever addon-API outcome. No secure frames anywhere in this module.

## 1. Layout

One strip, one anchor (`HogHealsHUDAnchor`), default 260×(18+12+14) px, centred, y = −180 (Sean's
Quartz position). Rows top→bottom:

1. **Castbar** — 18 px
2. **Mana bar** — 12 px, carries the FSR drain overlay + tick spark
3. **Info line** — text, 14 px: pacing (left) · rank advice (right)

Drag with `/hh unlock` (shared with Frames) or independently (`hud.followFrames = false`).
Per-row toggles; hidden rows collapse the strip.

### 2.1 Castbar (`Castbar.lua`)
State machine driven by player events: `UNIT_SPELLCAST_START / STOP / FAILED / INTERRUPTED / DELAYED /
SUCCEEDED / CHANNEL_START / CHANNEL_UPDATE / CHANNEL_STOP`, unit filter `player`. Reads
`UnitCastingInfo("player")` / `UnitChannelInfo("player")` for name, icon, start/end ms, notInterruptible.
- Fill direction: cast fills left→right, channel drains right→left.
- Text: spell name (+ " → TargetName" when `showTarget`), remaining seconds at `precision` decimals.
- **Latency segment**: on START, `select(4, GetNetStats())` (world ms) → red segment of that width at the
  bar end (the part of the cast you can't interrupt in time).
- Spark at the fill edge. Colours: cast, channel, uninterruptible (separate), failed flash (0.3 s red).
- GCD sliver: 2 px bar under the castbar, from `GetSpellCooldown(GCD_REFERENCE)` where the reference is
  the class's cheapest instant (Priest: Renew; Shaman: Healing Wave? no — Lightning Shield; Paladin:
  Blessing of Might; Druid: Rejuvenation). Cheap, optional, off by default.
- `hideBlizzard` → `CastingBarFrame:UnregisterAllEvents()` + hide (re-register on disable).

### 2.2 Mana bar + FSR (`Mana.lua`)
- Bar = `UnitPower("player", MANA)` / max; text mode `cur/max | percent | none`. Hidden when the
  character has no mana (Warrior/Rogue) or the row is disabled.
- **Five-second rule**: on `UNIT_SPELLCAST_SUCCEEDED` for player, if mana now < mana before → start FSR
  at `GetTime()+5`; a cyan overlay drains across the bar over 5 s; text "5s" ticks down optionally.
- **Tick spark**: outside FSR, every observed mana *increase* (poll 0.05 s via OnUpdate, cheap) marks
  a tick; next expected tick = last + 2.0 s; spark travels across the bar between ticks. Ticks pause
  during FSR and resume on the first post-FSR gain (matches the addon Sean uses).
- Drinking / Innervate / Evocation just look like big ticks — no special-casing.

### 2.3 Pacing (`Pacing.lua`)
- Fight = `PLAYER_REGEN_DISABLED` → `PLAYER_REGEN_ENABLED`. Timer text `m:ss`.
- Every 1 s in combat sample mana; `delta = mana_now − mana_prev`; `burn = EMA(−delta, α=0.2)` clamped
  ≥ 0 (regen inside samples is already netted).
- **OOM ETA** = `mana / burn` when burn > 0 (else "∞"). Text `OOM 2:10 · 1:35` → amber < 60 s, red < 20 s.
- Optional `targetLength` (default 300 s): `projected = mana − burn × (targetLength − elapsed)` →
  "at 5:00: 18%". Pure functions `Pacing.Step(state, mana, t)` / `Pacing.Eta(state)` are unit-tested.
- Resets on regen enabled; out of combat the line shows last fight's summary for 10 s, then hides.

### 2.4 Rank advisor (`RankAdvisor.lua` + `Data/HealRanks.lua`)
- Data: `HealRanks[spellName] = { coeff = c, ranks = { {rank=1, level=L, avg=A}, ... } }` for
  Priest (Lesser Heal, Heal, Greater Heal, Flash Heal, Renew, Prayer of Healing), Shaman (Healing Wave,
  Lesser Healing Wave, Chain Heal), Paladin (Holy Light, Flash of Light), Druid (Healing Touch, Regrowth,
  Rejuvenation), split `era` / `tbc` tables, generated from LibHealComm's `spellData` by
  `dev/gen_healranks.py` (runs the lib's data loader in lupa with `GetSpellInfo` stubbed).
  Downrank penalty: heals learned ≥ 20 levels below the player scale the coefficient as the game does —
  Classic formula `min(1, 1 − (20 − (spellLevel − playerLevel... )))` is applied per LibHealComm's
  own logic (copied as a *formula*, not code).
- Known ranks: scan the spellbook once at login and on `SPELLS_CHANGED` (`GetSpellBookItemName(i,
  BOOKTYPE_SPELL)` → name, "Rank N").
- `+healing` from `GetSpellBonusHealing()` (Era + TBC).
- `RankAdvisor.Pick(spell, missing, bonus, margin)` → lowest known rank where
  `avg + coeff × bonus ≥ missing × margin` (margin default 0.9), else highest rank. Pure, unit-tested.
- Display: while hovering a HogHeals frame (hook `ClickCast.OnEnter/OnLeave`), info line right side
  shows two configured spells: `GH r4 (1.6k) · FH r6 (1.1k)`. Optional mini-text on the hovered frame
  (`hud.advisorOnFrame`). Hidden when nothing is hovered or unit is full.
- **Limit (stated in options):** advisory only. Secure buttons cannot change rank in combat.
  `/hh rankmacros` prints `/cast Greater Heal(Rank N)` lines for every known rank of the configured
  spells so the user builds their rank keys once.

### 2.5 Options tab "HUD"
Position (x, y, follow frames), width, row heights, textures/fonts (LibSharedMedia), castbar (icon,
target name, latency, GCD, hide Blizzard, colours, precision), mana (text mode, FSR colour, tick colour,
show ticks), pacing (enabled, target length, thresholds), advisor (spell A/B per class, margin, on-frame
text), per-row enable toggles.

## 3. Data flow
```
UNIT_SPELLCAST_* ──► Castbar state ──► bar/text (OnUpdate while casting only)
UNIT_POWER_UPDATE + 0.05s poll ──► Mana bar, FSR window, tick spark
PLAYER_REGEN_* + 1s ticker ──► Pacing samples ──► info line (left)
ClickCast.OnEnter(button) ──► RankAdvisor.Pick(...) ──► info line (right) / frame mini-text
SPELLS_CHANGED ──► spellbook rank scan
```

## 4. Error handling
Same rails: every event handler in `pcall` → `HogHeals:LogError`; module disables a row (not itself)
when its data source is missing (e.g. `GetSpellBonusHealing` nil → advisor row hidden with one notice).
OnUpdate scripts only run while a cast/FSR/tick animation is active.
