Toast on first login: HogHeals suggested a healer click-cast layout. Open /hh click-cast to edit.
Click a frame with a mouse button + modifier to cast on that player. Right-click a slot to pick a spell from your spellbook; left-click a bound slot to set its rank and resurrect. Two input layers, independent of each other: Click-cast (this tab, mouse) and hover-binds (Bindings tab, keyboard keys). Set both and both fire. If a Bindings entry uses the same mouse button + modifier as a slot here, this grid wins. Saved for this character only. Plain Left / Right click keep target / menu unless you bind them. Works in combat; changes made in combat apply when it ends.
