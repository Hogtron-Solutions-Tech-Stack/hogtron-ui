## 2. What's new tonight (in the order you'll notice it)

### Unit frames — `HogUI Units` (PR #39)
Player, target, target-of-target, pet (focus exists but is off by default).
- Flat class-coloured health bar (players) / reaction-coloured (NPCs), thin power bar, name, level with `+` / `R`
  / `Boss`, health text (default "current + percent"), power text, raid icon, `+` when you're in combat, `zz` resting.
- **Left-click targets, right-click opens the unit menu** (they're secure buttons). Target/pet/ToT appear and
  disappear on their own, in combat too.
- **Target:** debuffs in a row under the frame (outline coloured by dispel type), buffs under those; Blizzard's own
  target cast bar is adopted and restyled *above* the frame (Blizzard's bar already copes with hidden cast timings).
- Blizzard's player/target/pet frames are hidden while these are on.
- Defaults flank the bottom centre like ElvUI: player left, target right, small frames beside them.
- Move: `/hh units unlock`, drag, `/hh units lock`. `/hh units reset` puts them back.
- Options: `/hh` → Units (General + one tab per frame: size, power bar, name, level, text size, offsets; target:
  cast bar, auras).

### Skin — `HogUI Skin` (PR #40)
Restyle of Blizzard's own pieces. Nothing is replaced, so bindings, paging, Edit Mode, sorting and every click
keep working.
- **Action bars:** gryphons / end caps / page arrows gone; every button flat: dark backdrop, 1 px outline,
  trimmed icon, keybind text, macro names hidden. Cooldown numbers on buttons switched on.
- **Bottom menu buttons + bag slots:** backdrop art gone, one ink strip behind each group, bag slots flattened.
- **Bags:** styled when opened — art off, ink panel, flat `x`, item outline coloured by quality (uncommon and up).
- **Tooltips:** ink panel with outline, flat health bar; options for text size and cursor anchoring.
- **Your buff/debuff icons** (top right) flattened; **XP/reputation bar** flat.
- **Blizzard's windows** (character, spellbook, quest log, escape menu, vendor, mail, trade, bank, talents,
  settings, popups…) on the ink panel with a flat close button. Any window can be excluded in the options
  (World Map is excluded by default).
- **Vendor automation:** at a merchant, grey junk is sold and gear repaired with your gold, one chat line says
  what happened. Guild repair is an option, off.
- **Info bar** (ElvUI's "datatexts"): a slim strip at the very bottom — gold, durability, bag space, fps,
  latency, clock by default; coordinates, friends, guild, experience available. Click a readout to open its frame.
  8 configurable slots, draggable when unlocked.
- `/hh skindiag` prints which Blizzard pieces were found on this client and which weren't.

### Quests & map, nameplates, chat — additions (PR #36)
- Quests you accept are **watched automatically** (option).
- Nameplate **cast bars** flattened.

60 fps frame budget, memory per addon and current fps. Costs nothing when not measuring.
**Please run it once tomorrow during a normal fight** — it's the answer to "is this slowing anything down".

## 5. What is not verified, honestly

- **Nothing in this document has been seen in the game.** The test harness models what we've measured on the
  beta (secret values, the nameplate structure, events that throw, the 0×0 bar), but it can't model Blizzard's
  frame *names* on this client. Everything is looked up by name and skipped when absent — so the failure mode
  is "a piece keeps Blizzard's look", not an error. `/hh skindiag` tells us which.
- The unit frames' right-click menu depends on `togglemenu` existing on this client. If right-click does
  nothing, tell me.
- Adopting Blizzard's target cast bar assumes it's a child of `TargetFrame` (true on every client I know).
- The vendor automation has never touched a real vendor. It's capped at 60 items per visit.
- The test harness cannot catch one class of bug on this client: testing a hidden ("secret") value for
  true/false. I review for it by eye; the game is the only real check.
