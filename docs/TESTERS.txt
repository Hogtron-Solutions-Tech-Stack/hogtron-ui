HogTron UI - tester notes (v0.1.0 beta, October 2026)
======================================================

Thanks for testing. What this is, how to install it, what to try, how to tell us what broke.
Ten minutes is plenty; an hour of normal play is gold.

WHAT IT IS
----------
HogTron UI is a UI suite for World of Warcraft: Forever (and Classic Era / Anniversary). One opinionated
look - ink panels, flat bars, a cyan line - and a set of modules you can turn on and off:

  HogHeals          core: profiles, options (/hh), performance meter
  HogHeals_Frames   party / raid frames built for healing (hover-cast, dispel, DoT + buff rows, test mode)
  HogHeals_Units    player / target / target-of-target / pet / focus frames
  HogHeals_HUD      cast bar, swing timer, mana bar with five-second rule, info line
  HogHeals_Bars     your own action bars (Bartender-style), hover-and-press key binding
  HogHeals_Plates   nameplates: flat bar, quest icons, target marks, cast bar, DoT skull / reapply mark
  HogHeals_Quests   quest tracker with the GO row, minimap pins, square minimap, addon-button drawer
  HogHeals_Atlas    dungeon guide: levels, bosses, loot, dungeon quests, gear upgrades, Where next
  HogHeals_Training what the class trainer has for you, before you get there
  HogHeals_Meter    damage / healing meter on the game's own numbers
  HogHeals_Chat     chat restyle, URL copy
  HogHeals_Skin     Blizzard's bags, menu bar, tooltips and windows in the same look, info bar

(Folders say HogHeals because the suite grew out of the healer frames; that is the folder name only.)

INSTALL
-------
1. Download HogTronUI-<version>.zip from the Releases page.
2. Unzip. You get a dozen folders named HogHeals*.
3. Drop ALL of them into  World of Warcraft\_classic_beta_\Interface\AddOns\  (or _classic_era_ /
   _classic_ for the other clients). The folder HogHeals must be there; every other one needs it.
4. Start the game (a full start, not /reload, the first time). Type  /hh  for the options.

A setup wizard asks what you heal with and what to score gear for. Skip it if you like; /hh wizard brings it back.

TRY THESE (five minutes)
------------------------
  /hh test 5        five fake party members with health, DoTs, buffs, dispels - do the frames look right?
  /hh next          Where next: dungeons, quests and zones for your level, nearest first
  /hh go            the GO row's pick (top of the quest tracker) - does it make sense where you stand?
  /hh train         after one visit to your class trainer: what is waiting, what comes next, what it costs
  /hh session       time played, xp an hour, time to the next level
  /hh perf 30       thirty seconds of CPU / memory per module - paste the summary line in your report
  Fight something:  swing timer under the cast bar; DoT a mob and watch for the skull / red X by its plate.

KNOWN LIMITS ON FOREVER
-----------------------
The Forever client hides some numbers from addons in combat (health, auras, names can be "secret").
Where that happens a feature goes quiet instead of erroring: incoming heals, missing-buff warnings,
the DoT skull. /hh diag and /hh platediag print what this client allowed.

WHEN SOMETHING BREAKS
---------------------
1. /hh diag          then /reload. The diagnostics are written to
   WTF\Account\<you>\SavedVariables\HogHeals.lua - attach that file.
2. A screenshot of the problem, with the chat window visible if there was an error.
3. One line: what you did, what you expected, what you saw.
4. Open an issue on the GitHub repo (Issues tab) or send it to Sean / Anthony directly.

Options you changed are safe to keep: a new version never resets your profile.
